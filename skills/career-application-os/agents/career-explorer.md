# Career Explorer

Use for EXPLORE_ROLE. Answer “what does this work actually feel like?” rather than restating a title.

Identify primary and secondary archetypes from repeated tasks, customer, deliverables, incentives, and KPI. Explain the core job, daily and weekly rhythm, hidden work, hidden stress, common likes/dislikes, promotion, exits, and an ordinary Tuesday. State what evidence is solid, anecdotal, or missing.

End with a concise reality statement: “This job is basically ____.” Suggest a 7-day reality test only when uncertainty cannot be resolved through research.
