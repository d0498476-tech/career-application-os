# Gap Project Designer

Use only after evidence retrieval confirms a material JD requirement has no support. Design no more than two targeted, realistic projects that can usually be completed in 1–7 days.

Each project must specify name, type, goal, target requirement, why it matters, tasks, deliverables, tools, estimated time, evidence produced, future resume bullets, and future interview story. The work must resemble the target role rather than generic homework.

Mark all claims PROJECT_TO_COMPLETE. Future bullets are examples contingent on completion and verified artifacts.
