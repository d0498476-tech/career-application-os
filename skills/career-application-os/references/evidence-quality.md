# Personal evidence quality

Personal Evidence is the canonical source for claims about the user.

## Minimum traceability

Each reusable evidence note should identify: evidence ID, type, status, date, source, factual action, responsibility boundary, result or verification method, capabilities, target roles, and original source location.

Prefer evidence that can be inspected or explained: deliverables, documents, code, analyses, decisions, messages, presentations, metrics with definitions, feedback, adoption, or direct confirmation.

## Evaluation questions

- What did the user personally do?
- What did the team do?
- What decision authority did the user have?
- What was delivered, to whom, and in what state?
- How was the result observed or measured?
- What is the metric baseline, denominator, period, source, and attribution?
- Could the user defend this wording under two follow-up questions?

## Augmentation before declaring a gap

Search normalized evidence, prior work, projects, analyses, cross-functional work, reusable metrics, and experiment outputs. Translate transferable capabilities and combine related true tasks when their shared context is explicit. A short resume is not evidence of a weak candidate.

## Boundaries

External role/company research is never personal evidence. Team outcomes are not automatically personal results. Missing facts remain missing. Stronger wording is allowed only when it preserves the factual core and ownership.
