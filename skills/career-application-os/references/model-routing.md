# Model routing

Check whether the current environment supports collaboration and permits delegation. This skill does not carry authorization from a previous user or environment. Higher-priority instructions and the current user's scope determine whether delegation may occur.

## Route when available

- Mechanical extraction, classification, sorting, deduplication, narrow evidence lookup, keyword extraction, and formatting may use an available lower-cost model when authorized.
- Role synthesis, career strategy, evidence conflicts, experience translation, resume positioning, difficult interview preparation, and final review stay with the primary capable model.

Use at most two mechanical collaborators at once for a normal application. Give each a bounded input and output contract; do not send the entire Vault. The primary agent must reconcile conflicts and own the final evidence boundary.

If collaboration or model selection is unavailable, use the same small-context, incremental workflow in one agent. Never claim that routing happened when it did not.
