# Application deliverables

Create 04_Applications/Company_Role_YYYY-MM-DD using a filesystem-safe name. Generate only files supported by actual analysis.

APPLICATION must not end at Job Match. The normal minimum sequence is Role Analysis → Evidence Mapping → Resume Strategy → Tailored Resume → ATS Review → Interview Preparation → Application Decision → Application Folder. Reuse fresh Role Analysis and Company Research instead of regenerating them.

## Normal package

- 01_JD.md: verbatim JD, URL/source, capture date, parsed requirements
- 02_Role_Reality.md: company-specific role reality when new analysis is needed
- 03_Company_Intelligence.md: relevant company facts and sources when missing or stale
- 04_Source_Evidence.md: external claim ledger and freshness
- 05_My_Fit.md: multidimensional fit and uncertainty
- 06_Experience_Mapping.md: requirement → evidence ID → status → wording/risk
- 07_Gap_Projects.md: only when a material gap can be addressed with up to two concrete 1–7 day projects
- 08_Resume_CN.md and/or 09_Resume_EN.md: application-ready, using VERIFIED and safe REFRAMED claims only
- 08_Resume_CN_Enhanced_Draft.md or equivalent: optional internal draft, visibly marked CONFIRM BEFORE APPLICATION
- 10_ATS_Check.md: must-have, nice-to-have, terminology, Covered/Partially Covered/Missing, and natural keyword placement
- 11_Cover_Letter.md: when relevant to the channel
- 12_HR_Message.md: concise platform/recruiter messages
- 13_Interview_Bank.md: prioritized questions and what they test
- 14_Interview_Answers.md: only where factual evidence supports useful answer drafts
- 15_Application_Decision.md: APPLY AGGRESSIVELY, APPLY AS EXPERIMENT, LOW PRIORITY, or SKIP
- 16_Confirmation_Checklist.md or an equivalent clearly named section: every unresolved candidate fact, its affected artifact, and the safest next verification step
- workspace.html: Tailor-generated local workspace when facts are sufficient

Do not create an empty file merely because it appears in this list. Link every personal claim to evidence IDs. Preserve the Master Resume under 01_My_Evidence/Master Resume and never overwrite it.

Unknown graduation date, degree, language certificate, location preference, relocation, salary expectation, visa/work authorization, and travel willingness are `NEED_CONFIRMATION`, not automatic workflow blockers. Continue independent work with visible placeholders or omission from application-ready claims. Block only when truthful resume generation is impossible, the user explicitly requires confirmation first, or no usable Personal Evidence exists.

For a gap project include name, type, goal, target JD requirement, why it matters, tasks, deliverables, tools, estimated time, evidence produced, resume bullets after completion, and interview story after completion. Mark it PROJECT_TO_COMPLETE until done.
