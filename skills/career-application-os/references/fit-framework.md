# Fit framework

Evaluate each dimension with evidence and uncertainty rather than collapsing them into one percentage.

| Dimension | Main question |
| --- | --- |
| Capability Fit | What can the user already demonstrate? |
| Interest Fit | Which repeated tasks create or drain curiosity? |
| Lifestyle Fit | Do travel, schedule, location, social load, and routine fit? |
| Stress Fit | Are quota, ambiguity, conflict, rejection, and urgency tolerable? |
| Pain Fit | Would the user willingly tolerate the worst recurring part for years? |
| Income Potential | What is plausible, conditional, and uncertain? |
| Learning Value | Which durable capabilities would compound? |
| Long-term Optionality | Which credible next roles become easier in three years? |
| Transition Difficulty | Which hard gates, evidence gaps, and ramp costs remain? |

For each dimension state current evidence, interpretation, uncertainty, and the cheapest next test. Explicitly output Best Part, Worst Part, Hidden Work, Hidden Stress, Likely Pain Point, Biggest Upside, and Biggest Risk.
