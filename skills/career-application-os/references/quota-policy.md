# Quota-efficient execution

- Start from indexes and normalized notes; never reload the full Vault or conversation history.
- Reuse evidence IDs, role intelligence, company intelligence, and prior application analysis.
- Summarize large raw sources once and keep links to originals.
- Return to raw material only for an exact metric, wording, provenance, conflict, or verification need.
- Do not regenerate unchanged files. Update only sections affected by new evidence.
- Before web research, list missing or stale claims; search only those.
- Pass collaborators only the relevant JD requirements, evidence excerpts, and target output.
- Keep the application folder modular so unchanged artifacts remain reusable.
- Prefer normal Markdown search and properties. Do not add a vector database in V1.
