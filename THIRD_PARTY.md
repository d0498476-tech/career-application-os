# Optional independent integrations

This repository does not vendor third-party skill code, templates, fonts, photos, or UI implementations.

- [ASu-skills](https://github.com/Hisn00w/ASu-skills): optional matching, resume, interview, evidence, and application tools. Consult the upstream LICENSE and the installed skill's instructions before use.
- [tailor-job-application-skill](https://github.com/ariasrsu/tailor-job-application-skill): optional application-workspace renderer. Consult the upstream distribution terms and installed instructions before use; no renderer source is redistributed here.
- [Official skill documentation](https://learn.chatgpt.com/docs/build-skills): reference documentation only.

Integration references describe handoffs, not a sublicense of an upstream project. Generated personal outputs belong in a user's private Vault rather than this distribution.
